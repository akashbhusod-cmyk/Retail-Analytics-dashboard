# Retail Analytics & Customer Intelligence Dashboard

An interactive and data-driven Retail Analytics Dashboard built using **Python**, **Streamlit**, **Plotly**, **Pandas**, and **Scikit-learn** using the Brazilian Olist E-Commerce dataset.

This dashboard provides deep business insights into:
- Sales performance
- Customer behavior
- Product analytics
- Payment analysis
- Delivery performance
- Customer segmentation
- Geographic trends

The project transforms raw e-commerce data into actionable business intelligence through modern interactive visualizations and KPI tracking.

---

# Dashboard Features

## Business Overview
- Total Revenue Analysis
- Total Orders Tracking
- Average Order Value (AOV)
- Delivery Performance Metrics
- Customer Review Analysis
- On-Time Delivery Tracking

## Product Analytics
- Top Performing Categories
- Revenue by Product Category
- Review Score Analysis
- Revenue vs Customer Satisfaction
- Product Performance Tables

## Customer Intelligence
- RFM Customer Segmentation
- Customer Lifetime Value Analysis
- Cohort Retention Analysis
- New vs Returning Customers
- Customer Clustering using KMeans

## Geographic Insights
- State-wise Revenue Analysis
- Delivery Performance by Region
- Customer Distribution Analytics
- On-Time Delivery Comparison

## Payment Analytics
- Payment Method Distribution
- Installment Analysis
- Category-wise Payment Trends
